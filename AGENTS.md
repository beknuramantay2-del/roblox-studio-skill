# AGENTS.md

Этот репозиторий содержит Agent Skill для разработки в Roblox Studio.

## Как работать с задачами по Roblox

Любая задача, которая касается Roblox, Luau, Roblox Studio, GUI/ScreenGui, RemoteEvent, DataStore, моделей или геймплея — начинается с загрузки скилла `roblox-studio`.

1. Прочитай `skills/roblox-studio/SKILL.md` целиком, прежде чем писать код.
2. Открывай файлы из `references/` по мере надобности — SKILL.md говорит, какой файл под какую ситуацию.
3. Правила из скилла имеют приоритет над твоими привычками по умолчанию. Особенно про UI-стиль и анти-баг чек-лист: они существуют потому, что дефолтный вывод модели тут стабильно промахивается.

Если нативный инструмент `skill` доступен (opencode, Claude Code) — вызывай его вместо ручного чтения файлов, чтобы контекст расходовался экономно.

## Как работать над самим репозиторием

- Правки в скилл вносятся в `skills/roblox-studio/`, это единственный источник истины. Установленные копии — симлинки, дублировать содержимое не надо.
- Фронтматтер `SKILL.md`: поле `name` обязано совпадать с именем папки (`roblox-studio`), иначе клиенты скилл не подхватят.
- `description` — единственное, что агент видит до загрузки скилла. Меняя его, сохраняй триггерные слова (Roblox, Studio, Luau, GUI, MCP), иначе скилл перестанет срабатывать.
- Держи `SKILL.md` компактным. Всё, что длиннее пары абзацев, уезжает в `references/`.
- Код в `snippets/` должен быть рабочим и типизированным (`--!strict`). Это шаблоны для копирования в реальные проекты, а не псевдокод.
