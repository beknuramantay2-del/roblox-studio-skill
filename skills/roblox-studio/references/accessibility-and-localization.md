# Доступность и локализация

Детский UI должен быть понятен без мелкого текста и точного наведения.

## Accessibility

- touch targets минимум 44x44 фактических пикселя;
- контраст текста и фона проверяй без опоры только на цвет;
- не используй hover как единственный сигнал;
- `Activated` и controller navigation для интерактивных элементов;
- reduced motion option для пользователей, которым неприятны пружинки и вспышки;
- не мигай быстро и не перегружай экран постоянными эффектами;
- важные действия подтверждай текстом, иконкой и звуком, но звук должен отключаться.

## Localization

Не вшивай фразы в код механики. Используй ключи и таблицы локализации, учитывай более длинные строки, RTL-языки, plural forms и формат чисел. UI должен выдерживать текст длиннее русского или английского.

Не складывай смысл только из эмодзи: их отображение различается по платформам. Давай текстовую альтернативу и проверяй шрифт.
