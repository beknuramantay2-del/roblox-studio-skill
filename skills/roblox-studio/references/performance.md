# Производительность

Целевое устройство — дешёвый телефон, а не твой компьютер. В Studio на мощной машине всё летает, поэтому оптимизацию нельзя оценивать на глаз в редакторе.

## Бюджет кадра

Кадр на телефоне — примерно 16 миллисекунд на всё. Отсюда правила.

**Не делай в каждом кадре то, что можно делать реже.** Проверка расстояния до магазина не обязана происходить 60 раз в секунду.

```lua
-- плохо
RunService.Heartbeat:Connect(function()
	checkAllShops()
end)

-- хорошо: 5 раз в секунду достаточно, разницы игрок не заметит
local accumulator = 0
local INTERVAL = 0.2
RunService.Heartbeat:Connect(function(dt)
	accumulator += dt
	if accumulator < INTERVAL then return end
	accumulator = 0
	checkAllShops()
end)
```

**Кэшируй ссылки за пределами цикла.** `workspace:FindFirstChild("Map").Coins` каждый кадр — это обход дерева десятки раз в секунду впустую.

**`RenderStepped` только для камеры.** Он блокирует отрисовку: тяжёлая работа там напрямую съедает FPS. Остальное — `Heartbeat` или `PostSimulation`.

**Не тяни физику там, где хватит анимации.** `TweenService` и `CFrame` дешевле, чем неотъякоренные части с констрейнтами.

## Память и объекты

Главный источник роста памяти — не текстуры, а забытые соединения и объекты. См. `bug-prevention.md`, раздел про утечки.

- Частые эффекты (пули, искры, всплывающий текст) переиспользуй из пула вместо `Instance.new` каждый раз. Создание и удаление сотен инстансов в секунду вызывает рывки от сборки мусора.
- `Debris:AddItem` на всё временное. Объект без плана на удаление живёт до перезапуска сервера.
- Много одинаковых декоративных частей — объединяй в одну модель и по возможности в `MeshPart`. Тысяча отдельных частей рисуется дороже, чем один меш.

## Репликация

Каждое изменение свойства объекта в `Workspace` летит всем клиентам. Массовые правки в цикле по тысяче частей завалят сеть.

- Remote-ы шли по делу, а не каждый кадр. Обновление счётчика монет — по факту изменения, не по таймеру.
- Отправляй минимум данных: `id` вместо целой таблицы предмета, которую клиент и так знает из `Config`.
- Пакуй частые мелкие обновления в одно пореже. Двадцать remote в секунду на игрока при полном сервере — это уже проблема.

## Загрузка

- Предзагружай важные ассеты через `ContentProvider:PreloadAsync`, но только критичное: иконки UI и звуки кнопок. Предзагрузка всего затягивает вход в игру.
- `StreamingEnabled` включай для больших карт — но тогда клиентский код обязан выдерживать отсутствие дальних объектов (см. `bug-prevention.md`).

## Как измерять

Не на глаз. В плейтесте: F9 (Developer Console) для ошибок и логов, Ctrl+Shift+F2 для статистики производительности, MicroProfiler для поиска, что именно жрёт кадр. Память смотри в течение 10-15 минут игры: важна не стартовая цифра, а растёт ли она. Растущая память = утечка.

Оптимизируй по данным, а не по интуиции. Правки "на всякий случай" усложняют код и обычно не там, где реальная проблема.
