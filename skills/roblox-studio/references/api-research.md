# Исследование Roblox API

Для средней модели этот файл обязателен при незнакомом или редко используемом API. Roblox API меняется, поэтому память модели не является источником истины.

## Карточка API

Перед кодом запиши коротко:

- класс или сервис;
- точная сигнатура метода;
- сторона выполнения: server/client;
- параметры и типы;
- возвращаемое значение;
- yield или не-yield;
- ограничения, permissions и rate limits;
- deprecated ли API;
- минимальный официальный пример.

Ищи в актуальной документации Roblox Creator Hub. Сначала точное имя класса/метода, затем его наследование и Enum-параметры. После этого сверяй пример с текущей версией Studio.

## Красные флаги

Остановись и проверь документацию, если видишь `is not a valid member`, `attempt to call a nil value`, неизвестный Enum, новый сервис, monetization, DataStore, MemoryStore, MessagingService, TeleportService, debugger или testing API.

Не выдумывай сигнатуру. Если документация недоступна, не выдавай непроверенный API как готовый код: предложи безопасный fallback или пометь место, которое требует проверки.

## После исследования

Вставь в код только минимально нужную часть API и оставь ссылку/заметку в документации проекта, если решение хрупкое. После этого проверь Script Analysis и реальный runtime, потому что корректная сигнатура всё ещё может быть применена не на той стороне.
