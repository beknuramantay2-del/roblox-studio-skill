# Версии, откат и синхронизация

Любая крупная правка должна быть обратимой. Git хранит Luau и конфигурацию, а Studio Version History хранит checkpoints места. Используй оба, если проект не чисто файловый.

## Перед крупной правкой

1. Зафиксируй текущий commit или Studio Version History checkpoint с понятной заметкой.
2. Запиши изменяемые файлы, DataModel paths и ожидаемый результат.
3. Не смешивай рефакторинг с новой логикой.

## Выбор workflow

- Studio напрямую: Version History, маленькие транзакции и `_draft` для новых объектов.
- Script Sync: файлы на диске синхронизированы со Script-объектами, проверяй конфликты перед записью.
- Rojo: source файлов является истиной, Studio используется для визуальных и runtime-проверок.
- Team Create: не редактируй одновременно тот же Script без проверки владельца и конфликта.

Не заставляй пользователя переходить на Rojo: сначала определи существующий workflow. Не смешивай несколько источников истины без явного правила.

## Откат

Откатывай только последний связный change-set. После rollback проверь дерево, Script Analysis, Output и повтори исходный сценарий. Не удаляй рабочие пользовательские объекты ради чистоты.
